# website

SvelteKit app, deployed to Netlify at [27984.netlify.app](https://27984.netlify.app).

## Developing

Install dependencies and start a dev server:

```sh
bun install
bun run dev
```

## Building

```sh
bun run build
```

You can preview the production build with `bun run preview`.

## Deploying

Pushes to `main` on GitHub automatically trigger a production deploy on Netlify.
